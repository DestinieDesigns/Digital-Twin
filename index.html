Destinie AI Twin Studio

This is the source repository, not the running studio.

GitHub is showing the project's index.html. The studio is a local app: it needs the Bun API and a SQLite database on your own computer, so it cannot run on GitHub Pages, and no private media is ever uploaded to a hosted site. Run it locally and open http://127.0.0.1:5173. 

bun install
bun run setup
bun run dev
